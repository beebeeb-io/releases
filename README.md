This repository is published as a GitHub Pages site at **[releases.beebeeb.io](https://releases.beebeeb.io)**. It hosts the artifacts that clients fetch to update or install themselves — nothing here is a buildable project, and **`desktop/latest.json` must never be edited by hand**.

The root URL redirects to **[beebeeb.io/download](https://beebeeb.io/download)**.

## What's here

| Path | Purpose |
| --- | --- |
| `desktop/latest.json` | Tauri v2 auto-update manifest. The desktop app polls this to discover new versions. |
| `cli/install.sh` | Compatibility shim for older links. It hands off to the canonical `bb` installer below, which checks the archive's SHA-256 before installing. |
| `cli/Dockerfile.e2e` | Throwaway container that installs `bb` through `cli/install.sh`, for manual end-to-end checks. |
| `index.html` | Redirect to `beebeeb.io/download`. |

## Installing the CLI

Use the canonical installer. It is generated by [cargo-dist](https://github.com/axodotdev/cargo-dist) on every [`cli` release](https://github.com/beebeeb-io/cli/releases), checks the downloaded archive against the SHA-256 recorded at release time, and installs `bb` to `~/.cargo/bin`:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://get.beebeeb.io | sh
```

`https://releases.beebeeb.io/cli/install.sh` still works and runs that same installer. It also refuses to install when `sha256sum` is missing, so a download is never installed unchecked. Set `INSTALL_DIR=<dir>` to place a single `bb` binary in `<dir>` instead.

Tests: `sh tests/cli-install.test.sh` serves a fake GitHub locally and checks that a tampered archive is rejected and a clean one installs.

## How it's updated

The [`desktop`](https://github.com/beebeeb-io/desktop) release workflow writes `desktop/latest.json` here on every published release, using a token scoped to `contents:write` on this repo. Manual edits to it will be overwritten by the next release. The files under `cli/` are maintained by hand. CLI binaries are published on the [`cli` GitHub releases](https://github.com/beebeeb-io/cli/releases), not here.
